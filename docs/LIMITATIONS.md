# Limitations

Stated plainly and without hedging: a 3B model follows instructions less reliably than
a 70B; classifier-based injection detection is bypassable; the rails are defense in
depth, not a guarantee; the 4K context window limits result-set size and multi-turn
depth; reversible pseudonymization keeps its map in process memory; text-to-SQL accuracy
is not formally evaluated; seed data is synthetic (PROJECT_PLAN.md §4.5).

Not written until Phase 4.
